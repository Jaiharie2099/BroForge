# Spider Bro Showcase

Editable native test arena with two troopers, a breakable crate, a low swing ceiling, and a ladder. It is a feature-test arena, not a completed campaign with a victory route. Create a campaign project named Spider Bro Showcase with id spider-bro-showcase, initialBro Spider Bro, and dependency spider-bro; write this design.json into it through MCP, then play_project. The gameplay GIF uses this actual arena.
